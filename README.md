# UniTrade

UniTrade is a campus marketplace that allows university students to buy, sell, and exchange pre-owned items within their campus. It provides a secure and affordable platform for students to connect and trade essential products.

## Features

- User authentication
- Buy and sell products
- Browse product listings
- Search and filter items
- Responsive interface

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
